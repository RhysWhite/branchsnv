# Security policy

BRANCHSNV processes local text files and does not access the network. It should
still be run only on files from trusted sources because unusually large or
malformed inputs may consume substantial memory or processing time.

## Supported versions

Security fixes are applied to the most recent released version.

## Reporting a vulnerability

Please report security concerns privately through GitHub's **Report a
vulnerability** feature. Do not include sensitive data in a public issue.

A report should include the affected version, operating system, a minimal
reproducer, and the observed impact. Reports will be acknowledged before any
public disclosure.
